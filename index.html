Box-Jenkins Mathematical Rigor & Stationarity

Forecasting highly volatile assets like Bitcoin requires satisfying strict structural constraints rather than deploying unverified models. This project implements the full Box-Jenkins framework. To control the severe non-linear variance, a Multiplicative Decomposition layout was enforced. Unit root validation via the Augmented Dickey-Fuller (ADF) Test (p-value: 0.795) formally proved non-stationarity, driving the implementation of a mathematical log-transformation coupled with a first-order chronological differencing loop.

Stochastic Modeling & Rolling Forecast Pipeline

Autocorrelation and partial autocorrelation tracking maps (ACF/PACF) were evaluated alongside automated AIC/BIC optimization criteria to select a parsimonious ARIMA(0,1,1) execution model. Because static long-term boundaries decay quickly on unpredictable distributions, an adaptive rolling forecast pipeline was engineered. The engine dynamically re-calibrates parameter matrices at each time step, appending previous real historical ticks to optimize the next prediction window, achieving an empirical Mean Absolute Percentage Error (MAPE) of 1.76%.

Generalized Linear Model (GLM) Deployment

To achieve mathematical validity, the architecture shifted toward a Generalized Linear Model (GLM) Gamma framework utilizing a Log link function, naturally adapting to positive continuous target spaces. Data integrity was safeguarded by evaluating Cook's Distance thresholds, filtering out 87 influential observations to prevent estimation bias. The final optimized system achieved an Akaike Information Criterion (AIC) score of 20,947, significantly outperforming linear benchmarks and isolating precise risk multipliers—such as quantifying that smoking status scales annual charges by a factor of 4.58x.

Data Ingestion, Transformation & Star Schema Modeling

This project constructs a comprehensive Business Intelligence environment to audit and contrast the historical trajectory of Apple Inc. (AAPL) against the market standard S&P 500 index. Raw financial distributions extracted from Yahoo Finance were ingested via Power Query. The ETL layer cleans transactional records, standardizes diverse data formats, and handles adjusted closing fields to build a highly optimized, cross-filtered Star Schema data model.

Advanced DAX Engineering & Interactive Restitution

The core analytical intelligence layer uses custom DAX (Data Analysis Expressions) vectors. Implemented dynamic rolling moving averages to smooth price fluctuations, trend delta metrics to calculate relative asset performance against the index, and an industrialized annualized volatility calculation ($\sigma\sqrt{252}$) driven by historical daily returns. Visual reporting supports chronological drill-through and conditional KPIs, allowing stakeholders to isolate custom windows.
